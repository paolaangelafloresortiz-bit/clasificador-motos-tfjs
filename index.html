Tipos de motos reconocidos

El modelo fue entrenado para diferenciar tres categorías de motocicletas.

Moto deportiva

Motocicletas diseñadas principalmente para rendimiento, velocidad y conducción deportiva.

Moto naked

Motocicletas de estilo urbano caracterizadas por una estructura más expuesta y versátil.

Moto scooter

Motocicletas orientadas principalmente a la movilidad urbana y al uso práctico.

Sobre el proyecto

Tecnologías utilizadas para desarrollar el sistema de clasificación.

Machine Learning

El modelo fue entrenado utilizando imágenes de motocicletas organizadas en diferentes categorías para realizar clasificación automática.

Teachable Machine

Se utilizó Teachable Machine para crear, entrenar y probar el modelo de clasificación mediante imágenes.

TensorFlow.js

TensorFlow.js permite ejecutar el modelo directamente en el navegador y realizar predicciones sobre nuevas imágenes.
